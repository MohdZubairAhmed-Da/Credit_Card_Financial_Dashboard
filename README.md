**Credit Card Financial Dashboard**

## Project Overview

This project focuses on analysing credit card customer and transaction data using Power BI and SQL. The dashboard presents financial performance indicators, customer demographics, transaction trends, and credit card usage patterns in an interactive visual format.

## Tools Used

- Power BI
- SQL
- DAX

## Project Objectives

- Monitor credit card revenue and transaction performance.
- Analyse customer demographics, including age, gender, and income groups.
- Compare revenue and transaction trends across different weeks.
- Understand credit card usage and customer activity.
- Present key performance indicators through interactive dashboards.

## Key Features

- Weekly revenue tracking and comparison with the previous week.
- Customer segmentation by age and income.
- Analysis of transaction amounts and transaction counts.
- Revenue analysis by gender and credit card category.
- Geographic analysis of credit card transactions.
- Tracking of activation and delinquency rates.

## Key Insights

The project report highlights the following findings from its dataset:

- Overall revenue was reported as 57M.
- Total interest was reported as 8M.
- Total transaction amount was reported as 46M.
- Blue and Silver credit cards accounted for 93% of overall transactions.
- Texas, New York, and California accounted for 68% of the reported contribution.
- The overall activation rate was 57.5%.
- The overall delinquency rate was 6.06%
